# Hygiene multiplies bacterial infection

Hygiene’s second tooth is sepsis, not zombie `transmitted`. Dirty hands and dirty wounds use the same band table. Filthy still blocks the Doctor Job; the player can treat anyway.

**Status:** accepted

Two consumers, one table:

| Band | Sepsis mul |
|---|---|
| `clean` | 1.0 |
| `a_little_dirty` | 1.25 |
| `dirty` | 1.75 |
| `filthy` | 2.5 |

**Treat:** the *treater’s* band muls the sepsis roll at the treat action. **Open wound, daily:** the *patient’s* band muls the passive sepsis check. Cleaning the wound is its own existing factor; it does not replace hygiene.

No new injury type. Harness may retune the numbers; the two consumers stay.

## Considered options

- Treat roll only — rejected; docs/04 names both dirty hands and dirty wounds.
- Defer the mul — rejected; scent-only hygiene is flavor.
