# .hermes/plans: design records and screenshots

Historical. Each dated folder holds the plan or the pictures one piece of work produced, kept
because docs/23's record, docs/30's decisions and docs/32 link to them as evidence.

Nothing here is an instruction. Several plans name files that no longer exist (`HANDOFF.md`,
`AGENTS.md`) and branches that were merged long ago. For what to work on, read `CLAUDE.md` and
docs/23's "What's left in Milestone 2". For why something is shaped the way it is, read docs/30.

New screenshots for the owner to judge still go here, in a folder named
`YYYY-MM-DD_<piece>/`, linked from the docs/23 record that cites them.
